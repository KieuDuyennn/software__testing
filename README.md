# Software Testing coursework

Coursework for Software Testing (CSC13003), University of Science, VNU-HCM, 2026.

| Homework | Topic | Summary |
|---|---|---|
| [HW01](HW01/) | QA job market and defect research | Research on the QA/QC job market, a study of real software defects, and test cases for a physical product. |
| [HW02](HW02/submission/) | Domain testing and BVA on EShop | 73 test cases (53 domain, 20 boundary) designed for 4 EShop features, 71 executed, revealing 9 confirmed bugs. |
| [HW03](HW03/) | GUI and usability testing on EMS | A 62-item checklist run on 6 screens, a 28-cell cross-platform matrix and 5 real user sessions (SUS mean 67.0), producing 28 findings. |
| [HW04](HW04/) | Playwright automation on EShop | 139 data-driven cases across 3 browsers (417 executions), yielding 45 confirmed issue-level findings. |
| [HW05](HW05/) | Performance testing on EShop with JMeter | Load, stress, spike and soak tests on a login-to-checkout journey (including a 168-user burst on a 17-user baseline and a 15-minute soak), all at 0% errors, plus one documented cart-retention risk. |
| [HW06](HW06/) | API testing on EShop with Postman/Newman | 386 API test cases for 4 endpoints (366 AI-generated and audited, 20 added), 16 unique bugs including an IDOR and a broken admin authorization check, run as a GitHub Actions gate and re-run against the patched backend. |

The EShop work continues with CI in [eshop-quality-engineering](https://github.com/KieuDuyennn/eshop-quality-engineering).
