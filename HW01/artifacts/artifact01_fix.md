### 20. Shai-Hulud npm Dependency Supply Chain Attack

- **Source Link:** [https://thehackernews.com/2026/05/2026-year-of-ai-assisted-attacks.html](https://thehackernews.com/2026/05/2026-year-of-ai-assisted-attacks.html)
- **Description:** Attackers deployed a malicious automated package generation framework to flood the npm registry with over 500 tainted open-source code libraries using dependency confusion techniques.
- **Severity:** Critical
- **Consequences:** Over 487 developer environments and production networks leaked internal environment secrets, enabling attackers to steal roughly $8.5 million from users' crypto wallets.
- **Solution:** The npm registry security staff removed the malicious modules, blacklisted the associated developer accounts, and introduced stricter publication validation measures.
