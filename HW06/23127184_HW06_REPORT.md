## 3. Method

For each API, the four-step pipeline in Section 6 of the brief:

1. **Generate with AI** — driven step by step through domain partitions, state
   transitions, security (SEC-01..SEC-07) and schema validation, never as a
   single generic prompt. → `docs/phases/*/01-generate.md`
2. **Audit** — every generated case labelled VALID / INVALID / INCOMPLETE with
   reasoning; the invalid and incomplete ones corrected.
   → `docs/phases/*/02-audit.md`
3. **Extend** — at least five cases per API that the AI missed, with a
   diagnosis of why. → `docs/phases/*/03-extend.md`
4. **Execute** — Newman runs, HTML reports, failure triage.
   → `docs/phases/*/04-execute.md`
