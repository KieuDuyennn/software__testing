# Generator diagram

Section 11 of the brief: the test-generator diagram is one of three items the
TAs verify as **not AI-generated**. It must be self-drawn.

## What is here

| File | What it is |
|---|---|
| `generator-design.png` | The submitted diagram, laid out by the student in draw.io on 2026-08-30 |
| `generator-design.drawio` | The editable source, extracted from the `mxfile` chunk the draw.io export embeds in that PNG |

The machine-generated Mermaid and SVG drafts that used to sit beside it were
deleted once the drawing was finished, so nothing in this folder can be
mistaken for the submitted artefact. Open the `.drawio` file at
<https://app.diagrams.net> to see the shape geometry the student positioned by
hand.
